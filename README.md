# Global Superstore Sales Dashboard

## Overview

This project showcases an interactive Power BI dashboard built using the Global Superstore dataset. The dashboard provides a comprehensive overview of sales performance, profitability, customer behavior, and regional trends through interactive visualizations and business-focused KPIs.

## Dashboard Objectives

- Monitor overall business performance using key metrics.
- Analyze sales and profit trends over time.
- Identify the most profitable product categories.
- Discover top-performing customers and regions.
- Support data-driven business decision-making.

## Key Performance Indicators (KPIs)

- Total Sales: **$12.64M**
- Total Profit: **$1.47M**
- Total Orders: **25K**
- Profit Margin: **11.61%**
- Average Order Value: **$504.99**

## Key Insights

- Technology generated the highest profit among all categories.
- Sales showed steady growth from 2011 to 2014.
- Zürich emerged as the top revenue-generating region.
- Furniture contributed the lowest profit.
- The business maintained a healthy profit margin of 11.61%.

## Dashboard Features

- Interactive category and date slicers
- KPI cards for business overview
- Profit analysis by category
- Category-wise sales distribution
- Annual sales trend analysis
- Top customers by sales
- Top revenue-generating regions
- Dynamic filtering and drill-down capabilities

## Tools & Technologies

- Data Modeling
- Data Visualization
